# 📊 Unemployment Analysis & Forecasting

## 📌 Overview

This project analyzes unemployment trends in India using Python. It includes data visualization, state-wise analysis, COVID-19 impact study, and a basic machine learning model for prediction.

## 🛠️ Technologies Used

* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn

## 🚀 Features

* Trend analysis over time
* State-wise comparison
* COVID-19 impact analysis
* Future prediction using ML

## ▶️ How to Run

1. Open the notebook in Google Colab
2. Upload the dataset
3. Run all cells

## 📁 Files Included

* Notebook (.ipynb)
* Dataset (.csv)
